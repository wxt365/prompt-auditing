客户端接入

POST /v1/responsesPOST /v1/chat/completionsPOST /images/generationsPOST /images/edits

Chat Completions 同时支持 POST /chat/completions，两种路径使用相同安全规则。图片接口不带 /v1 前缀；图片客户端自动附加 /images/... 时，请将本地基础地址末尾的 /v1 去掉。生成使用 JSON，编辑支持 JSON 和 multipart；图片内容不做识别。

网关不读取客户端认证文件，不保存请求中的认证密钥；上游负责验证凭证。
